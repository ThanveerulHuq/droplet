Droplet Privacy Policy

Last updated: August 8, 2026

Droplet estimates the water associated with ChatGPT usage and provides local usage summaries.

Read the methodology behind Droplet’s estimates.

Data handled

On ChatGPT pages, Droplet measures only the character length of completed assistant responses to calculate water-use estimates. It does not retain, store, transmit, or make available prompt text, response text, conversation titles, browsing history, cookies, account information, or clipboard contents.

Local storage

Droplet stores aggregate usage counters, hashed conversation identifiers and hashed message identifiers used to prevent duplicate counts, dates and timestamps used for usage summaries, and extension settings and preferences using Chrome’s local extension storage. This information remains on your device and is not synced to your Google account.

Sharing and network activity

Droplet makes no network requests. It has no analytics, telemetry, advertising, crash reporting, remote code, or third-party data sharing. Data is never sold, transferred, or used for advertising.

Chrome Web Store user-data policy

Droplet uses data solely to provide its user-facing water-estimation feature and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
