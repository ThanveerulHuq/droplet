# 💧 Droplet

Droplet is a Chrome extension that estimates the water associated with your AI
chat usage. It measures only response length to produce an estimate and does
not collect prompt or response text.

## Install

[Install Droplet from the Chrome Web Store](https://chromewebstore.google.com/detail/droplet-water-used-by-you/mfcpanmpbdibncpahkiadagjiokihedo)
